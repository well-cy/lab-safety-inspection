# 错误分析与真实场景验证方案（验收阶段）

> 本阶段目标：**不新增功能、不微调模型**，把当前 SH17 官方 YOLOv8s + SE-CS 规则引擎
> 放到**真实场景**里做一轮验证，明确"哪些是检测错、哪些是规则错、哪些是场景不适配"，
> 并给出下一步（微调 / 补拍）的依据。
>
> 核心结论先行：
> 1. **规则引擎本身逻辑正确**（10 张图全部按"检测到的 PPE"与区域规则正确分级）；
> 2. **所有误判都来自目标检测层**——主要是 `lab_coat` 大量漏检（白大褂）、`gloves` 偶发漏检、
>    `person` 多检/误检；
> 3. `lab_coat` 目前用 SH17 的 `medical-suit / safety-suit` **映射**，语义上不等价于真实验服，
>    是当前最大的准确率缺口；
> 4. ROI 演示验证通过：**ROI 外不判违规、进入 ROI 按规则触发**。

## 二、lab_coat 专项分析（为什么不可靠、怎么办）

### 2.1 现状：SH17 里没有"实验服"这个类别

SH17 数据集的 17 类 PPE 只包含 `medical-suit`（医用防护服/连体服）和 `safety-suit`（安全防护服），
**并不存在独立的"lab coat / 实验服 / 白大褂"类**。系统为了复用规则，用：

```python
# ai/detector.py  CLASS_ALIAS 映射（示意）
"medical-suit": "lab_coat",
"safety-suit": "lab_coat",
```

把两者**语义上"看作"实验服**。这不是等价，是近似。

### 2.2 为什么白大褂会漏检（4 张白大褂场景全部漏检）

| 图 | 真实着装 | SH17 预期类别 | 检测结果 |
|---|---|---|---|
| t01 | 白色长袖**白大褂** | medical-suit / safety-suit | **未检到任何 suit** |
| t02 | 白色**白大褂**（配领带、胸前机构logo） | 同上 | **未检到** |
| t07 | 白色**白大褂**+乙烯基手套 | 同上 | **未检到** |
| t09 | 白衣者（户外） | 同上 | **未检到** |

根因（模型侧）：
1. **训练样本占比极低**：SH17 以工业/建筑安全场景为主，`medical-suit` / `safety-suit` 多出现在
   全套连体防护（如 CDC 那种、化工现场）——**白大褂这类半开放式、纽扣式、常见于生化实验室的服装，几乎不出现**。
2. **外观差异大**：
   - **领口/开合**：白大褂为**开襟纽扣/系带**，明显区别于连体服的**拉链全封闭**。
   - **松紧**：白大褂宽松、含袖子褶皱；连体服贴身、硬挺。
   - **材质反光**：白大褂棉质漫反射；连体服(如 CDC)为合成/反光面料。
   - **搭配**：白大褂常配衬衫领带/便服、患者常仅上半身可见；连体服全身覆盖。
3. **结果**：模型从未"见过"白大褂这个视觉模态 → 在 0.35 阈值下召回为 0。

### 2.3 为什么 t06 却"好像好使"

t06 是 CDC **连体防护服**——恰好就是 SH17 里真正的 `medical-suit` 模态，所以被识别为
`medical-suit`(conf 0.78) 成功映射成 `lab_coat`。这是**语义巧合**，不是系统"认识实验服"。
也就是说：系统认的不是"实验服"，而是"连体防护服"。当真实场景换成**白大褂**，就塌了。

### 2.4 解决方案（按优先级）

| 方案 | 做法 | 成本 | 是否推荐（当前阶段） |
|---|---|---|---|
| **① 自采数据微调（推荐，第二阶段）** | 采集真实验服/白大褂样本，本地以 **lab_coat** 真实标注，微调 YOLOv8s 让模型认识该模态 | 中 | ✅ 根治。这是本阶段最该走的路 |
| ② 扩充类别别名 | 在映射表中再并入类似可用类（如 `apron` 等），快速缓解 | 低 | ⚠️ 治标，且 SH17 无对应类，难大幅提升 |
| ③ 用"白衣+长袖"启发式兜底 | 检测到 person 且胸前景色近白、长袖时**提示**可能缺实验服 | 低 | ⚠️ 仅作提示/提醒，不作为判罚依据，易误报（t09 白衣、t05 无白大褂黑T恤反例） |
| ④ 调整规则为"口罩+手套"（砍掉 lab_coat 强制项） | 默认规则不再强制实验服 | 低 | 🔴 不建议——违背课程"实验室安全"主诉求，且规避了真正的缺陷 |

> **当前阶段决策**：暂不训练（遵循用户要求），只做**数据侧验证**。等自采测试集跑出
> `lab_coat` 的实际 Recall（预计很低）后，作为"是否微调 lab_coat"的一手证据。

## 三、ROI 演示测试（已实现并通过）

### 3.1 目的
验证系统核心业务规则：**"人员只有在进入实验操作区 ROI 后，才按规则判违规"**。

### 3.2 实现
脚本 `tests/roi_demo.py`，合成 640×480、30fps、8 秒（240 帧）视频：
- 1 名"人员"（携带 `gloves` + `lab_coat`，**刻意缺口罩**）从左向右穿过系统真实 ROI。
- ROI 使用数据库真实配置：实验室A → 实验操作区，像素 `(140,86,563,441)`，required_ppe=`['gloves','lab_coat','mask']`。
- 人员中心从 x=120 → 200：前 50 帧静止在 ROI 外，50–70 帧穿越边界，之后停在 ROI 内。

### 3.3 运行结果（关键帧）

```
ROI「实验操作区」像素=(140,86,563,441)  required_ppe=['gloves', 'lab_coat', 'mask']
=== ROI 演示逐帧关键点 ===
 frame    cx  inROI  判定      缺失PPE       截图
     0    120 False  跳过      -           -
    57    141 True   一般违规   未佩戴口罩    roi_demo_057.jpg
```

| 帧 | 人员中心 x | inROI | 判定 | 说明 |
|---|---|---|---|---|
| 0–56 | 120–140 | ❌ | **跳过** | 中心在 ROI 左侧边界外 → 即便缺口罩，**不判违规** |
| 57 起 | ≥141 | ✅ | 一般违规 | 中心进入 ROI → 立即按 `mask+gloves+lab_coat` 判断，缺口罩 → 生成"未佩戴口罩"事件 + 保存截图 |

### 3.4 结论
- ✅ **ROI 外不判违规**：人员缺 PPE 但中心未进入 ROI → 不评估。
- ✅ **进入 ROI 触发**：中心一进入即按规则判断，缺口罩立即判"一般违规"。
- ✅ **违规事件与截图**：进入 ROI 首帧生成事件并保存 `outputs/screenshots/roi_demo_057.jpg`（画面红色框+“未佩戴口罩”标签）。
- 输出视频：`outputs/roi_demo.mp4`（可回放秒级变化）。

**说明**：本轮为**规则链路**验证（引擎 evaluation 正确），与"能否检测到人/PPE"无关；单帧无真实视频输入，
用构造式检测对象走通"ROI 判断 → 规则 → 事件 → 截图"全链路，供验收观察。

### 4.2 每类拍摄方法要点

- **A（12）**：白大褂+口罩+手套**三者齐**，正面平视，躯干+双手+头部全在画面内，背景是实验台。
- **B（12）**：同 A 但**摘掉口罩**（其余齐全），确保能看到口鼻（体现"缺口罩"）。
- **C（10）**：同 A 但**不戴手套**（手部露出）。
- **D（10）**：同 A 但**不穿白大褂**（便服/短袖），只在操作区操作。
- **E（12）**：只戴其中 1 种或 0 种，参考 t05 场景。
- **F（10）**：2 人，一人齐全、另一人缺 ≥2 种；**两人横向分开**、身体不重叠。
- **G（8）**：3–5 人集中操作区，有的齐全有的缺；层次错开，尽量不遮挡面部/手部。
- **H（10）**：人员站在操作区**外**（走廊/门口/普通区），**故意缺 PPE**，验证不判违规。
- **I（6）**：0.5–1.5m 特写，分别拍手部(手套)、面部(口罩/护目镜)、躯干(白大褂)。
- **J（6）**：2–5m 全身，人物占画面 1/3–1/2，正面为主。
- **K（4）**：>5m 远景，人物很小（占画面 <1/6），考察 person 小目标。
- **L（6）**：人物分别 45°、侧 90°、背对镜头。
- **M（6）**：均匀日光灯为主，另各 2 张补强光正对、逆光、暗光。
- **N（8）**：人物部分被仪器/烧杯/他人遮挡（遮住手臂手套、半边脸、下半身白大褂）。

### 4.3 拍摄硬性要求

- **设备/机位**：手机或单反，像素 ≥1280×720；尽量固定机位，避免晃动。
- **一致性**：同一台设备、同一批人、同一实验台，尽量减少无关变量。
- **构图**：人物完整入框；多人时人物分隔。
- **ROI 记录**：拍摄时记住"操作区"大致范围，回来标注时同步标 ROI，避免"人在区内却标成区外"。
- **避免**：插画/截图/WEB 图；不拍 t03/t04 那种线稿；不拍外部合影（避免 t09 类场景误用）。

### 4.4 标注要求（测试集同样需要 GT 才能算指标）

- 工具：labelImg（YOLO 格式）/ CVAT / Roboflow（导出 YOLO txt）。
- 格式：`cls cx cy w h`（归一化），与 `tests/evaluate_model.py` 一致。
- **按系统 6 类标注**：person=0, mask=1, gloves=2, lab_coat=3, goggles=4, helmet=5。
- **lab_coat 只标"真实验服/白大褂"**——不映射、不做任何别名替换，量出模型对实验服的真实能力。
- person 必标；PPE 一个对象一个框（两只手套两个框）；被遮挡 <50% 可不标并记录。
- 记录每张图属于上表 **A~N 哪一类**，便于分组统计。
