## 五、t01~t10 场景实测

评测脚本：`tools/eval_t01t10_6cls.py`（新写，适配 6 类单模型架构）

| 图 | 场景 | 新 6 类模型判定 |

| t02 | 砷实验室 | 一般违规：未戴口罩 |
| t03 | NIH 移液 | 严重违规：未戴手套+未穿实验服 |
| t04 | NIH 移液 2 | **无检测**（模型能力边界） |
| t05 | PCR 科学家 | 严重违规：未穿实验服+未戴口罩 |
| t06 | CDC 连体防护服 | **严重违规：未穿实验服+未戴口罩** |
| t07 | 雌激素实验 | 一般违规：未戴口罩 |
| t08 | 研究生化学实验室 | **无检测**（模型能力边界） |
| t09 | 实验服典礼 | 7 人，多数严重违规 |
| t10 | 分析化学学生 | **无检测**（模型能力边界） |

### 5.1 t06 专项（本次重点）

**t06 的 coverall 没有被检出为 `coverall`，而是被低置信度认成了 `lab_coat`（conf=0.20/0.14）。**

低阈值扫描证据（`conf=0.01`）：
```
gloves   0.6715 | person 0.6709 | gloves 0.6347 | lab_coat 0.2031 | gloves 0.0874 ...
```
即 t06 上**没有任何 coverall 输出**。

**含义**：t06 的连体服属于**训练集未见过的模态**（户外/街头/病房的连体服 vs. CDC 生物安全柜场景）。模型对这类分布外样本仍会退化成 lab_coat。

**业务影响**：t06 判「严重违规：未穿实验服+未戴口罩」。这正是 Route B' 口径的预期行为（连体服不满足 lab_coat），但**归因表述不准确**（实际是"模型没认出连体服"，而非"识别出连体服并判定不达标"）。

### 5.2 t04 / t08 / t10 无检测

三张图在 conf=0.35 下零检出；降到 0.15/0.05 才勉强出现 person。
- 属**模型能力边界**（非代码缺陷）
- 与 5 类时代表现一致，非本次换装引入的回归

## 八、待决问题

### 8.1 t06 类场景口径（需业务拍板）

**问题**：全副武装防疫人员（连体服+面罩+口罩+手套）被判「严重违规」，是否符合业务预期？

| 方案 | 改动 | 效果 |
|---|---|---|
| A. 维持现状 | 零改动 | t06 判严重违规；规则刚性，特殊场景靠区域豁免 |
| B. 加等价规则 | 规则层：检出 coverall 视为满足 lab_coat | t06 变为一般违规（仅缺口罩） |

**建议**：方案 B 更合理（"防护等级更高却判更严重违规"难以自圆其说）。但**前提是模型能稳定检出 coverall**——而 t06 恰恰检不出，所以方案 B 在 t06 上**当前无效**。
→ **推荐路径**：维持现状（方案 A），把 t06 作为"跨域泛化短板"如实写入报告；待补数据后再考虑等价规则。

### 8.2 coverall 数据量偏少

coverall 仅 402 框（其余类 1,500~3,300 框）。虽然 valid 上 AP50 达 0.769，但跨域（t06）失效。
**对策**：见 `docs/E5_7_补充_连体服图源清单.md`，可补 Roboflow「PPEs」数据集（7,582 图）。

### 8.3 mask 召回率低

dataset2 上 mask R 仅 44.1%（P 97.6%）。属高精度低召回，可考虑降 conf 或补数据。
