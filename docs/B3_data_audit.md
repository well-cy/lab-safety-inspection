# B3 数据集标注质量审计报告

- **日期**：2026-09-20
- **执行**：许婧雯（分工①：AI 模型 + 数据集 + AI 实验）
- **对象**：B3 公开数据集（data/raw/b3/，456 张图片 / 589 个标注框）
- **结论**：**B3 标注存在系统性右偏，放弃用于训练，转向公开数据集补充**（详见"决策"）

---

## 1. 审计方法

| 工具 | 说明 |
|---|---|
| `tools/filter_b3_clean.py` (v2) | 三档分级：bad（越界）/ suspect（可疑偏移或空标注）/ clean（可信） |
| `tools/draw_labels.py` | 通用标注画框可视化，供人工复核 |
| `tools/visualize_b3.py` | 原有抽检工具（12 张），本次审计的起点 |

**判定标准**（v2）：

- **bad**：任一类别框越界（框边界超出图片范围 [-0.05, 1.05]）
- **suspect**：无越界，但 Lab_coat 框中心 x > 0.65（B3 主体基本居中，偏右视为可疑），或标注文件为空（需人工确认是否真负样本）
- **clean**：有标注、无越界、Lab_coat 中心 ≤ 0.65

## 3. 典型案例

| 案例 | 问题 |
|---|---|
| `018_0003_012483` | Lab_coat 框 left=0.51 / right=1.37，越出图片右界 37%，仅罩住半件衣服 |
| `001_0043_008931` | 框中心 0.776、右边缘 1.003——偏移但恰好未越界，v1 口径漏网 |
| `001_0191_007077`、`015_0241_005036` | 图内明显有实验服，标注文件却为 0 字节（漏标） |

## 4. 根因分析

问题图片集中于 `crop_margin_0-1` 系列，框普遍**整体向右偏移并越出图片右边界**。推断：**标注在裁剪前的原图上进行，裁剪生成 crop_margin 版本时坐标未重新映射**，导致系统性右偏。

## 5. 决策

2026-09-20 评估：clean 仅 22 张（其中 test split 为 0），无法支撑 E4 训练；修复需重标或找回原图重映射，成本高于收益。**决定放弃将 B3 用于训练，转向公开数据集补充**（候选：labcoat_si 566 张、GSFC Lab Coat Detection 229 张，均 CC BY 4.0）。原始数据保留于 `data/raw/b3/` 作为审计证据，不删除。

> ⚠️ 待办：本决策需同步组长确认；B1 自采数据到位后同样适用本审计流程。

## 6. 附：其他发现

- 5 张含非 ASCII（印地语）文件名的图片，OpenCV 在 Windows 下无法读取，训练前需重命名
- 15 张空标注图中，部分（gettyimages/istockphoto 系列）与水印问题清单重叠
