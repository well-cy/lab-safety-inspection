# 开源资源与数据来源说明

> 本项目采用「开源模型 + 公开数据集 + 二次开发」路线，未从零训练模型。
> 本文档如实记录所有使用的开源资源，明确区分开源基础能力与本项目的二次开发内容。

## 1. 检测模型

### 1.1 主模型：SH17 官方 YOLOv8s 权重

| 项目 | 内容 |
| ---- | ---- |
| 名称 | SH17 PPE Detection 官方预训练权重（yolo8s.pt，本地重命名为 sh17_yolov8s.pt） |
| 来源 | https://github.com/ahmadmughees/SH17dataset （Releases v1） |
| 直接下载 | https://github.com/ahmadmughees/SH17dataset/releases/download/v1/yolo8s.pt |
| 框架 | Ultralytics YOLO（AGPL-3.0 License，https://github.com/ultralytics/ultralytics） |
| 论文 | SH17: A Dataset for Human Safety and Personal Protective Equipment Detection in Manufacturing Industry（arXiv:2407.04590） |
| 训练数据 | SH17 数据集：8,099 张图片 / 75,994 个实例 / 17 类 |
| 模型原始指标（官方, SH17 验证集） | P=81.5, R=55.7, mAP@50=63.7, mAP@50-95=41.7 |
| 使用限制 | 仓库未附独立模型 License 文件；论文声明数据集面向研究与商业用途开放；Ultralytics 框架为 AGPL-3.0。课程项目用于教学演示；若商业使用需再次评估 AGPL-3.0 义务 |

模型原始 17 类：
`person, head, face, glasses, face-mask-medical, face-guard, ear, ear-mufs, hands, gloves, foot, shoes, safety-vest, tools, helmet, medical-suit, safety-suit`

本项目通过类别映射（ai/detector.py 中的 CLASS_ALIAS）将其映射为 6 个业务类别：

| 业务类别 | 映射自 SH17 原始类别 | 说明 |
| -------- | -------------------- | ---- |
| person | person | 人员 |
| mask | face-mask-medical / face-mask | 口罩 |
| gloves | gloves | 手套 |
| lab_coat | medical-suit / safety-suit | 实验服（映射说明见下） |
| goggles | glasses / face-guard | 护目镜/面罩 |
| helmet | helmet | 安全帽 |

**重要说明（lab_coat 映射）**：SH17 无独立的 "lab coat" 类，其 medical-suit
（医用防护服/实验服类连体/白大褂着装）与 safety-suit（连体防护服）在视觉上与
实验室白大褂最接近，本项目将其映射为 lab_coat。该映射是近似处理，对纯白大褂
的识别效果需要在自采实验室数据上验证，属于已知局限（见 README「已知问题」）。

## 2. 公开数据集（候选分析）

| 数据集 | 地址 | 类别 | 规模 | 格式 | License | 结论 |
| ------ | ---- | ---- | ---- | ---- | ------- | ---- |
| SH17 | https://github.com/ahmadmughees/SH17dataset | 17 类（含 person/gloves/face-mask/medical-suit/glasses/helmet） | 8,099 图 / 75,994 实例 | YOLO txt | 开放（论文声明研究+商用） | ✅ 采用：类别覆盖最匹配 |

| CHV / GDUT-HWD / SHEL5K | 见 SH17 论文 Table I | 以安全帽/马甲为主 | — | — | 各异 | 排除：面向建筑场景 |

**结论**：第一阶段直接使用 SH17 官方 YOLOv8s 权重，不在本机重新训练。
若后续自采数据显示 lab_coat 识别不足，计划组合 Roboflow ppe-airbf（CC BY 4.0，
含 labcoat 类）做微调训练——这属于第二阶段工作。

## 4. 开源基础能力 vs 本项目二次开发

### 开源基础能力（非本项目贡献）
- Ultralytics YOLOv8 推理框架（模型加载、推理、NMS）
- SH17 官方预训练权重（PPE 目标检测能力本身）

### 本项目二次开发内容（原创部分）
1. 类别映射层：SH17 17 类 → 6 业务类别的映射与过滤（ai/detector.py）
2. Person-PPE 空间匹配模块：中心点包含 + 最近距离兜底的双策略归属算法
   （ai/ppe_matcher.py）
3. ROI 区域判断模块：归一化矩形区域配置与人员所在区域判定（ai/roi.py）
4. 安全规则引擎：可配置 PPE 要求、违规分级（一般/严重）、违规事件生成
   （rule_engine/engine.py）
5. 图片/视频处理管线：帧抽取复用（stride）、违规截图冷却去重、标注绘制
   （video/processor.py）
6. 数据库设计与读写（backend/database.py）
7. FastAPI 全套 API 与前端页面（backend/）
8. 测试用例体系与性能实测（tests/run_tests.py）
