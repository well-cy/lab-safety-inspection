## 二、异常输入实测：3 处会 500 / 写脏数据（建议测前先修）

### ❌ 1. 非图片/空文件上传 → HTTP 500（最高优先，随机测试必踩）

- 复现：
  ```bash
  printf 'not an image' > fake.jpg
  curl -X POST http://127.0.0.1:8000/api/detect/image -F "file=@fake.jpg" -F "lab_id=1"
  # → HTTP 500 Internal Server Error
  ```
- 实测三种都 500：**非图片内容伪装 .jpg**、**0 字节空文件**、**纯文本 .txt**。
- 根因（日志实锤）：
  ```
  File "video/processor.py", line 125, in process_image
      raise ValueError(f"无法读取图片: {image_path}")
  ValueError: 无法读取图片: ...\data\test\uploads\img_797686d8.txt
  ```
  `backend/main.py:139`（`detect_image`）与 `:185`（`detect_video`）**未捕获该 ValueError**。
- 即 `docs/PROJECT_STATUS.md` 已知问题 #4，属 **成员3 的 `backend/main.py`（独占文件）**。
- 建议最小修复（每处 3 行，diff 极小）：
  ```python
  # detect_image / detect_video 内
  try:
      result = process_image(...)          # 或 process_video(...)
  except ValueError as e:
      return JSONResponse({"error": str(e)}, status_code=400)
  ```
  顺带建议：上传时按 `file.content_type` / 扩展名白名单（jpg/jpeg/png/bmp/webp、mp4/avi/mov）先挡一层，并把非允许扩展名的落盘名统一成 `.bin` 后再判净。

### ⚠️ 2. 区域坐标无范围校验，可写入脏数据

- 复现（实测**被接受**并入库 `area_id=3`）：
  ```bash
  curl -X POST http://127.0.0.1:8000/api/settings/area \
    -F "lab_id=1" -F "name=x" -F "x1=5" -F "y1=-3" -F "x2=0.1" -F "y2=9" -F "required_ppe=mask"
  # → 200 {"ok":true,"area_id":3}
  ```
- 影响：ROI 越界/反向矩形（x1>x2）会入库，后续检测的「是否在区域内」判定不可预期。属已知问题 #5（成员3）。

### ⚠️ 3. `required_ppe` 无白名单校验

- 复现（实测入库 `area_id=4`）：
  ```bash
  ... -F "required_ppe=helmet,banana"   # → 200 {"ok":true,"area_id":4}
  ```
- 影响：规则引擎拿到未知 PPE 类型会静默不产生违规（或抛异常，取决于实现）。建议限 `{mask,gloves,lab_coat,goggles,helmet}`。

### ℹ️ 4. 删除不存在的区域返回 `200 {"ok":true}`（无 404）——轻微，可不修。

> 本次预检写入的测试数据（区 3/4、检测记录 96/97 及截图）**已即时清理/可清理**：
> 区 3/4 已 DELETE；`backend/labsafety.db` 已备份于 `outputs/_smoke/labsafety.db.bak`。

## 三、体验/演示风险（不是 bug，但随机测试会遇到）

### ⚠️ 5. 视频接口同步阻塞：默认 `stride=2` 时，16 s 视频要跑约 2 分钟，期间整个 API 无响应

- 实测：`stride=20` → 11.4 s；按默认 `stride=2`（200 帧）线性外推 **~110 s**。
- 随机测试建议：**视频只测 10 s 以内或手动把 stride 调大**；同时别在多标签页并发点检测。
- 属已知问题 #3（成员3：视频后台任务 + 进度查询，Phase 2 计划项）。

### ⚠️ 6. 前端图表走公网 CDN（`cdn.jsdelivr.net`）——断网/校园网受限时**全部图表空白**

- `backend/static/index.html:7`：
  `<script src="https://cdn.jsdelivr.net/npm/echarts@5.5.0/dist/echarts.min.js"></script>`
- 全文件**仅此一处外链**（其余无外部依赖），修起来干净：下载 `echarts.min.js` 到
  `backend/static/vendor/echarts.min.js` → 改这一行 script src 即可。
- 属已知问题 #7（**答辩风险**，成员4 的 `index.html` 独占文件）。

### ℹ️ 7. 站点模型与最新数据集不是一回事（提醒，非缺陷）

- 站点加载 `ai/model/labppe_v8s.pt`：**四类**（mask/gloves/lab_coat/goggles）、9-28 训练、E2/E4 底座。
- 组员① 的新库已是**五类、1,845 图**，但处于中间态（person 未补完，**禁止训练**）→ 暂无新权重可换。
- 所以：**站点检出效果 ≠ 数据集当前水平**；随机测试看到的是"旧模型的表现"。

### ℹ️ 8. 随机测试会持续堆积上传文件

- 每次上传都会落盘：`data/test/uploads/img_*.jpg`、`outputs/annotated/*`、`outputs/videos/*`、以及违规截图
  `outputs/screenshots/*`。测完可整目录清理（都是 gitignored 的运行产物）。
