- **教训**：见下方「本仓库 git 使用注意」

### 本仓库 git 使用注意（带斜杠分支的坑）

本仓库 `core.autocrlf=true` 且原先无 `.gitattributes`，且 **`refs/heads/` 下带 `/` 的分支（如 `feature/ai`）loose ref 写入会静默失败**，表现为：

- `git commit` 输出成功，但 `git log` / `git branch -v` 看不到新提交
- `git checkout -b xxx/yyy` 后 HEAD 悬空，`git status` 报 "not a git repository"
- `git tag a/b` 创建后 `git rev-parse a/b` 找不到

**应对**：
1. 新建带斜杠分支后，用 `git rev-parse --verify <name>^{commit}` 确认；失败则手动补 ref
2. 提交后若 `git log` 未更新，直接编辑 `.git/packed-refs` 中对应行指向新 SHA（并保持**字母序**，否则 `fsck` 报 `packedRefUnsorted`）
3. 已新增 `.gitattributes`（文本统一 LF）减少换行符抖动
