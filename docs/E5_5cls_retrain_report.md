## 4. 变化分析

### 提升的类
- **gloves（+9.2pt F1，+17.6pt AP50）**：提升最显著。基线时手套是弱项，重训后召回从 64.9%→62.8% 略降但**精确率大幅提升**（FP 更少），AP50 显著上升。
- **goggles（+8.4pt F1）**：之前 F1 仅 22.1% 的"最差类"，提升到 30.5%。虽有改善，**仍是全模型最弱项**。

### 下降的类
- **mask（-8.6pt F1，-9.2pt AP50）**：召回从旧基线降至 46.2%，漏检 100/186。**当前最需关注的问题**——精确率高达 96.6%，说明"检出的都对，但漏得多"，典型的召回不足。
- **lab_coat（-3.7pt F1）**：AP50 基本持平（0.901→0.897），属正常波动。

### 根本原因推断
类别数从 4→5 后，模型需同时学习 person 与 4 类 PPE，**容量在弱类之间重新分配**：gloves/lab_coat 数据多（449/127 GT），受益；mask 数据量中等（186）但视觉变异性大，出现召回下降。

## 6. 配置变更（本次一并提交）

`backend/config.py` 默认模型改为**存在即优先用自制 5 类模型**：

```python
_labppe = root / "ai" / "model" / "labppe_v8s.pt"
_default_model = _labppe if _labppe.exists() else (
    root / "ai" / "model" / "sh17_yolov8s.pt")
self.MODEL_PATH = _env_path("MODEL_PATH", _default_model)
```

- 有 `labppe_v8s.pt` → 用它（开箱即用，无需环境变量）
- 没有 → 回退 SH17（新成员克隆后仍可跑）
- 两者都可被 `LABSAFETY_MODEL_PATH` 强制覆盖

## 7. 后续建议

1. **mask 召回是当前首要短板**（漏检 100/186）。建议下一轮补 mask 多样性样本（尤其遮挡、侧脸、远距离小目标）。
2. **goggles 仍是最弱类**（F1 30.5%）。此前已发现 dataset2 的 goggles GT 偏少且视觉差异大，建议专项扩充。
3. person 召回（85.9%）低于 SH17（95.8%）。若后续对人数统计精度要求高，可考虑 person 数据增补或提高 person 类的采样权重。
4. 换装脚本与本次评估脚本已入库：`tools/swap_5cls_model.py`、`tools/eval_5cls_vs_4cls.py`。
