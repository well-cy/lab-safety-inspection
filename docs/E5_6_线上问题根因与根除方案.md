## 2. 已根除部分：后处理逻辑层（5 处规则）

全部为**确定性代码缺陷**，与模型能力无关，已彻底修复。

### 2.1 人物框近重复误合并
- **症状**：双人拥抱（两人框 IoU ≈ 0.52）被去重逻辑合并，报 1 人。
- **根因**：`_dedup_persons` 近重复判定阈值 IoU ≥ 0.5 过于激进。
- **修复**：收紧为 **IoU ≥ 0.85 且小框 ≥80% 被包含**（`_near_duplicate`）；同时 `detect()` 的 `predict(iou=0.5)` 抑制联合框。

### 2.2 PPE 归属容差不足
- **症状**：弯腰取药者手套检出但未归属（判为「未戴手套」）。
- **根因**：person 框只框住上半身，手套中心距框中心 268px > 旧距离兜底阈值 167px。
- **修复**：新增**扩张框归属规则**——person 框四周扩 40%，多框重叠时取面积最小者（`match_person_ppe` 规则 2）。

### 2.3 伪 person 框清理
- **症状**：6 人合影检出 9 人（6 真人 + 2 碎片框 + 1 联合框），口罩被伪框抢走归属。
- **根因**：YOLO 在密集人群下产出肢体碎片框与套多人的联合框，NMS 无法抑制。
- **修复**：新增 `_is_fragment`（中心被 ≥2 倍且**更高置信度**的框包含）与 `_is_union_box`（被 ≥2 个高置信框覆盖 ≥50%），`_dedup_persons` 改为**迭代删除直到稳定**。
- **踩坑**：初版碎片判定把被联合框套住的真人一起杀了。修法是**碎片判定的宿主必须更高置信度**——联合框置信度低，不能当宿主。

### 2.4 联合框猎手 + 衣料误检手套
- **症状**：医生病人图报 3 人（联合框比真框**大** 2.4 倍，碎片判定轮不到）+ 蓝牛仔裤误检为手套 conf 0.45。
- **根因**：① 联合框比被套真框更大，`_is_fragment` 的「被包含」条件不成立；② gloves 类训练集含大量非医用手套（见 §3.2），牛仔裤纹理被误召回。
- **修复**：新增 `_is_contained_lowconf`（联合框猎手：p 包含一个中心在内、≥80% 被包含、面积差 ≥2 倍的更高置信框 → p 是联合框）；新增 `_glove_dominates_person`（手套面积 ≥ 所叠最小 person 框 **35%** → 判衣料误检）。

### 2.5 碎片判定 PPE 豁免
- **症状**：机器人双人图报 1 人——老头被误杀，机械臂幻影存活。
- **根因**：老头上半身框被女研究员大框包含（面积差 2.85 倍）→ 被碎片判定误杀。
- **修复**：碎片判定加 **PPE 豁免**——框内含 mask/goggles/lab_coat 中心则说明是真人，不按碎片淘汰（`_contains_ppe_center`）。

## 3. 待根除部分：数据与模型层（3 类现象）

以下现象**代码无法修复**，已逐一验证到模型原始输出层。

### 3.1 医用连体防护服 lab_coat 召回 = 0

**证据**：4 人医用防护服图，无论 conf 降到 0.08，lab_coat 检出均为 0。

**根因（已定位到 manifest）**：

```
原始标签 Coverall 共 1522 框，处理方式：
  drop_class  → 1156 框   (直接丢弃)
  patch       →  331 框   (推断为 lab_coat，来自 ppedetect)
  keep        →   35 框   (保留为 lab_coat)
```

即：**医用连体防护服这一形态在训练集中的有效监督信号不足**。而 `dataset1`（17157 张）里的 lab_coat 标签以「Lab coat / lab coat」为主，是敞开式白大褂形态。

模型学到的是「敞开式白大褂 = lab_coat」，因此：
- 标准实验室敞开式白大褂 → 检出正常（F1 85.4%）
- 医用封闭式连体防护服 → 完全检不出

**这同时解释了现象 #3**：那张图 4 人全穿医用防护服，模型一个 lab_coat 都检不出，所以全判「未穿实验服」——**判定逻辑是对的，是输入特征不在模型学习范围内**。

### 3.2 mask 召回不足（46.2%，漏检 100/186）

**根因**：训练集类别量级严重失衡：

| 类别 | train 框数 | 占比 |
|---|---|---|
| gloves | 8048 | **最大** |
| person | 2851 | |
| lab_coat | 1767 | |
| mask | **1823** | |
| goggles | — | 最小 |

同时 mask 的**视觉变异性极大**（不同颜色、佩戴角度、遮挡程度），数据量中等却要覆盖极大变化范围，导致精确率 96.6% 但召回仅 46.2%——「检出的都对，但漏得多」。

### 3.3 机械臂误检为 person（无负样本）

**根因**：训练集**不含任何负样本**。manifest 中 `keep_as_negative` 仅 133 条，且为「无标注」的通用图，不包含机械臂/机器人这类「像人非人」的针对性负样本。

后果是连锁的：person 幻影 → 该幻影框内又检出 lab_coat/mask → 产生虚假合规判定。

### 3.4 数据域差距（根本性）

训练集来源构成：

| 来源 | 图片数 | 说明 |
|---|---|---|
| `dataset1` | **17157** | 通用 PPE 数据集（含大量高尔夫手套、工业护目镜等非实验室场景） |
| `ppedetect` | 472 | |
| `labcoat_si` | 490 | 实验服专项 |

**真实实验室场景图占比极低**。手套类 8048 框中大量来自高尔夫手套等，导致：
- 牛仔裤纹理被误检为手套（§2.4 现象）
- 运动手套与医用手套的特征混淆
- 白大褂 / 连体服 / 分工服三者边界模糊

## 4. 根除路线（按成本收益比排序）

### L1 · 后处理规则收紧（已落地，可选继续）
已完成的 5 处规则即为本层。可继续补充：
- **置信度阈值分级**：不同类别用不同 conf 门槛（如 lab_coat 降到 0.25 提召回）
- **ROI 区域约束**：结合已有 ROI 区域功能，非实验区降低灵敏度
- **时序稳定性过滤**：视频流中连续 N 帧命中才报违规，消除瞬时误报

### L2 · 数据补标（收益最高，优先做）
1. **重新纳入 Coverall**：把已 `drop_class` 的 1156 个 Coverall 框中的医用防护服，按 Route A 口径重新以 `lab_coat` 并入训练集 —— 这是一条**已有数据、零额外采集成本**的改进。
2. **真实实验室场景图批量入集**：补 mask / 手套 / 白大褂三类的边界样本，尤其遮挡、侧脸、远距离小目标。

### L3 · 负样本专项集（成本中等，收益明确）
- 收集机械臂 / 机器人 / 人体模型 / 海报人像等「像人非人」图，**不标任何框**直接进训练集。
- 这一条同时压下 person 幻影与由此产生的连锁 PPE 误报。

### L4 · 重训 + 阈值调优
- 合并 L2/L3 数据后重训。
- 按类独立扫描 conf 阈值，按目标 F1 为每类选定工作点。
- 考虑对外暴露「演示模式」：低阈值保召回，避免漏检在演示时观感差。

## 5. 对答辩的影响与建议

**可以明确说明的（加分项）**：
- 后处理管线具备完整的**伪框清理与归属容错机制**，且经过 6 轮真实问题驱动的迭代验证。
- 系统对「模型检出 → 归属 → 判定 → 分级」的解耦设计，使得模型弱项不会直接变成误报（如 conf 偏低时由合理性过滤兜住）。
- 连体服视作 lab_coat 是**明确的业务口径决策**（Route A），有文档记录，非实现疏漏。

**建议规避的（演示选图）**：
- 医用防护服场景图（lab_coat 召回 = 0）
- 含机械臂 / 机器人的自动化实验室图（person 幻影）
- 重度遮挡的显微操作特写（手部漏检）
- **推荐使用标准实验室场景图**：敞开式白大褂 + 口罩 + 手套 + 护目镜，模型在这类图上表现最好。

**保留说明（若被问到）**：
> mask 召回 46.2%、goggles F1 30.5% 是本模型当前的已知短板，根因是训练数据在类别量级与场景分布上不均衡。下一轮将通过补充真实实验室场景样本与负样本专项集来提升。
