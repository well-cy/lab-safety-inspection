# E5 补数据与重训方案

> 2026-09-30 制定。基于 E4 重训（valid mAP50=0.737）+ 09-28 演示实测 14 个问题场景的定位结论。
> 结论先行：**检测端代码已榨干（7 轮修复见 commit be17f8e），剩余问题全部是训练数据没覆盖的场景。**

## 1. 现状

| 项 | 状态 |
|---|---|
| 线上模型 | `ai/model/labppe_v8s.pt`（E4，30 epochs，valid mAP50 **0.737**） |
| 分数 | gloves 0.908 / lab_coat 0.873 / goggles 0.847 / **mask 0.320** |
| 验收线 | 0.924（未达标，差 0.187，短板明确在 mask 与 lab_coat 长尾形态） |
| 检测端增强 | 双尺度合并 + 切片复检 + 4 道几何过滤 + 倒影过滤（14 张回归图全过） |
| 算力 | 约 17 点（V100 = 2 点/小时，本轮重训预算 5~7 点，够） |

## 2. 训练数据现状（2026-09-30 实测统计）

| 类别 | train 框 | valid 框 | test 框 | train 占比 |
|---|---:|---:|---:|---:|
| mask | 1,630 | 173 | 59 | **8.8%** |
| gloves | 9,331 | 1,294 | 122 | **50.3%** |
| lab_coat | 2,380 | 145 | 37 | **12.8%** |
| goggles | 5,199 | 980 | 366 | 28.0% |
| 合计 | 18,540 | 2,592 | 584 | 100% |

**两个结构性问题：**
1. **gloves 占一半**，是 mask 的 5.7 倍——模型严重"手套偏置"：手套误检多（袖口/鞋子/倒影/裸手全是手套 FP），而 mask 是最大短板。补 mask 数据 + 控制手套比例是提分关键。
2. **lab_coat 只有 12.8%**，且形态长尾（背身/连帽/敞怀/特写）完全没覆盖——09-28 演示里"KIST 系列""三人防护服"等 lab_coat 漏检全是这一族。

## 3. 补数据清单（P0 → P2）

### P0 治短板（对 mAP 影响最大）

| # | 场景 | 目标量 | 治什么 |
|---|---|---|---|
| 1 | **mask 全形态**：外科口罩、N95、双滤盒防毒面具（正面/侧面/远距） | +800~1200 框 | mask AP50=0.32；防毒面具漏检（09-28 实测 640 下才有 0.60） |
| 2 | **lab_coat 长尾形态**：远景全身、背身/连帽防护服（KIST 系列那类）、敞怀+深色内搭、近距特写、亮反光背景 | +600~800 框 | 09-28 全部 lab_coat 漏检家族（全图/切片/1920 全失败） |
| 3 | **透明护目镜正面照** | +150~200 框 | 全图检不到、切片才 0.44 |

### P1 治误检（负样本，**不标框**或只标真目标）

| # | 场景 | 目标量 | 治什么 |
|---|---|---|---|
| 4 | 普通眼镜（近视镜，不戴护目镜） | +200~300 张 | 眼镜→护目镜误检（全图 0.61，几何上与真护目镜不可分） |
| 5 | 裸手入镜（持器械/交叉/叉腰）、白鞋、白大褂衣料特写 | +200 张 | 手套 FP 家族（0.45~0.87 不等） |
| 6 | 玻璃台面/反光地面场景 | +50~100 张 | 倒影手套 FP（代码过滤治标，数据治本） |

### P2 离线增广（**不用找图，脚本今天就能跑**）

| # | 内容 | 产出 | 治什么 |
|---|---|---|---|
| 7 | 现有 train 强 JPEG 压缩 + 噪声 + 降采样 | 3,252 张（30%） | 压缩图上 lab_coat 掉到 <0.06、演示图全是重压缩图的问题 |

### 采集规范（沿用 `docs/B1_采集SOP.md`）

≥3 人、≥3 种光照、近/中/远三种距离；新增数据**只进 train/valid，不进 test**（红线，见 E4 规划）；入库必过四关（红线去重 / pHash / 脏图 / 标注一致性审计）。

## 4. 离线增广（无需找图，可立即执行）

工具：`tools/aug_compress_noise.py`（默认干跑，不写文件；只动 train；标签原样复制）

```bash
# 1) 干跑看计划
.venv/Scripts/python.exe tools/aug_compress_noise.py --ratio 0.3 --dry-run
# 2) 生成到独立目录（约 3252 张，CPU 约 20~30 分钟）
.venv/Scripts/python.exe tools/aug_compress_noise.py --ratio 0.3 --out data/lab_ppe_aug
# 3) 抽检确认后合并进主数据集
.venv/Scripts/python.exe tools/aug_compress_noise.py --merge-from data/lab_ppe_aug
```

效果对照见 `outputs/_aug_compare.jpg`（左原图 / 右退化后，伪影程度与真实微信传图一致）。

## 5. 重训配方

```python
model.train(
    data="data.yaml",
    epochs=60,            # E4 的 30 轮 mask 还在爬升
    imgsz=640,
    batch=16,
    optimizer="SGD",      # E4 被 auto 选成 AdamW(lr=0.00125) 收敛偏慢
    lr0=0.01,
    lrf=0.01,
    momentum=0.937,
    weight_decay=0.0005,
    warmup_epochs=3,
    cos_lr=True,
    patience=20,
    seed=42,
)
```

- **起点**：yolov8s.pt 从头训（数据分布变化大：+30% 增广 + 新场景，续训易困在旧局部最优）
- **mask/lab_coat 过采样**（可选但推荐）：生成 train 图片清单 txt，把含 mask 或 lab_coat 的图重复 2 次，data.yaml 的 `train:` 指向该清单——对冲 gloves 50% 的失衡
- **续训前检查**（AI Studio 假完成教训）：确认无 best.pt 残留，只留 last.pt 判断续训；启动命令带 `export MPLBACKEND=Agg`
- **算力预算**：约 14000 张 × 60 epochs，V100 约 3~3.5h ≈ **6~7 点**（含环境开机开销）
- 数据上传沿用 `tools/aistudio_upload.py` + `docs/AIStudio训练指南.md` 流程

## 6. 验收标准

| 检验 | 门槛 |
|---|---|
| valid mAP50 总体 | **≥ 0.85**（E4 0.737） |
| mask AP50 | **≥ 0.55**（E4 0.320） |
| gloves / goggles | 回退 ≤ 3pp |
| 14 张回归图（09-28 定稿） | 全过，不新增 FP |
| 翻车场景复测（flip1~6 + KIST 系列） | KIST 家族 lab_coat 至少检出 1 张 |
| 压缩图专项 | 强压缩图上 lab_coat/mask 不再全灭 |

## 7. 执行顺序

| 步骤 | 谁 | 内容 |
|---|---|---|
| 1 | AI | ✅ 增广脚本已就绪，干跑验证通过 |
