## 0. 一句话执行版

**找 3–5 位同学，穿齐实验室 PPE，在真实验室里按「装备组合 × 距离 × 角度 × 光照 × 姿态」矩阵拍，
一轮 250–350 张、分 2–3 次拍完；不连拍、不修图、存 JPG、文件名用英文。
把文件夹路径发我，预处理/去重/预标注/抽检/入库我全包。**

> 关键变化（相对 B1 SOP）：本次**不只补白大褂**，而是**一次把人身上的 4 件 PPE 全拍进去**——
> 同一张图里同时出现 白大褂 + 口罩 + 手套 + 护目镜，**一张图贡献 4 个框**，采集效率翻 4 倍。
> 当前最大短板是 **mask（口罩）**，不是白大褂。

## 2. 采集任务包（照着拍，每包都有验收判据）

**拍摄核心技巧：把 PPE 穿成一整套再拍。** 每张图的框数构成如下——

| 装备组合 | 每图产出框 | 用途 |
|---|---|---|
| **A. 全套**（白大褂+口罩+手套+护目镜） | 4 框 | 效率最高，主力组合 |
| **B. 白大褂+口罩**（不戴手套/护目镜） | 2 框 | 补 lab_coat + mask |
| **C. 只戴口罩**（各类型口罩、各种戴法） | 1 框 | 专攻 mask 短板 |
| **D. 只戴手套**（操作状态特写） | 1 框 | 补低对比手套 |
| **E. 只戴护目镜**（正面/侧面/低头） | 1 框 | 专攻 goggles 短板 |
| **F. 多人同框**（2–5 人，穿不穿 PPE 混搭） | 多人 × N 框 | 治多人漏检 |
| **G. 空场景**（无人的实验室各处） | 0 框（负样本） | 治空场景误检 |

### 包 1 ── 口罩专项（P0，目标 400~600 框）

| 维度 | 要求 |
|---|---|
| 口罩类型 | 蓝色外科口罩、白色外科口罩、黑色口罩、N95/KN95、带呼吸阀 N95（各 15~25 张） |
| 佩戴状态 | 规范佩戴／戴在下巴（**标注为负样本，不标框**）／拿在手里 |
| 距离 | 近 1–2m 半身、中 3–5m 全身、**远 8–15m 小目标（≥1/3）** |
| 角度 | 正脸／侧脸（**侧脸至少 1/4**）／低头伏案（遮挡） |
| 多人 | 同框 2~4 人各戴口罩（**一次拿到多个口罩框**） |
| 张数 | **120~180 张** |

**验收判据**：口罩框 ≥400；含至少 3 种口罩类型；远景（8–15m）占比 ≥1/3；有侧脸与低头遮挡样本。

### 包 2 ── 护目镜专项（P1，目标 300~500 框）

| 维度 | 要求 |
|---|---|
| 类型 | 透明防溅护目镜（头带式）、大框护目镜、带侧翼护目镜、化学溅射镜 |
| 状态 | 正确佩戴／推到额头（**负样本**，不标框） |
| 距离/角度 | 近景正/侧面特写（判细节）＋ 中远景（判小目标）；**低头操作时护目镜反光**要有 |
| 负样本 | **普通近视眼镜（不标框）**——相机位 4 里最大的 goggles 误检源，需 30~40 张正脸戴眼镜图 |
| 张数 | **80~120 张** |

**验收判据**：护目镜框 ≥300；含推额状态与眼镜负样本各 ≥30 张。

### 包 3 ── 白大褂专项（P2，目标 400~600 框）

| 维度 | 要求 |
|---|---|
| 款式 | 白色系长袖/短袖、开襟/系扣、**蓝色实验大褂**（实验室场景内算 lab_coat） |
| 距离 | 近/中/**远（≥1/3）** |
| 角度 | 正面／侧面／**背面（≥1/4）** |
| 姿态 | 站立／行走中／弯腰伏案／坐着 |
| 状态 | 穿着／**脱下挂在椅背、钩子、手臂上**（约 15~20 张） |
| 张数 | **100~150 张** |

**验收判据**：lab_coat 框 ≥400；含背面 ≥25 张、脱下状态 ≥15 张、远景 ≥35 张。
**不收**：连体防护服（coverall）、防静电服、非实验室来源的蓝色洗手衣/隔离衣/刷手服。

### 包 4 ── 手套专项（P3，目标 150~250 框）

| 维度 | 要求 |
|---|---|
| 类型 | **白色丁腈手套、透明 PVC 手套**（低对比，重点）、蓝色丁腈（对照） |
| 状态 | 双手持物（试管/烧瓶/移液枪）／单手／手部遮挡 |
| 背景 | **白色台面 + 白色手套**（最难的组合，必须拍 20~30 张） |
| 张数 | **60~90 张** |

**验收判据**：手套框 ≥150；白/透明手套 ≥100 框；白台面白手套场景 ≥20 张。

### 包 5 ── 多人场景（P4，目标 150~250 图）

| 维度 | 要求 |
|---|---|
| 人数 | 2 人 / 3 人 / 4–5 人（各 ≥25 张） |
| 穿戴 | 混搭——有人穿白大褂有人没穿、部分戴 PPE（**负样本与正样本同框**，最贴近真实业务） |
| 遮挡 | 有人被仪器/他人部分遮挡（治漏检） |
| 场景 | 实验台并排操作、围桌讨论、走道迎面走来 |
| 张数 | **100~150 张** |

**验收判据**：**所有可见人体都标 person 框**（含被遮挡者）；2/3/4-5 人各 ≥25 张。

### 包 6 ── 空场景与相似物体负样本（P4，目标 150~250 图）

| 内容 | 张数 |
|---|---|
| 空实验室（无人，含仪器、试剂架、通风橱） | 40~60 |
| 空实验台/过道/门口 | 30~50 |
| 易误检物：**椅子、白墙、白鞋、玻璃反光、白色设备外壳、纸箱** | 40~60 |
| 悬挂的白大褂/空挂钩（无人穿着） | 20~30 |

**验收判据**：**全部不标任何框**（空标签）；须为实验室环境，不得用生活照凑数。

## 3. 拍摄规范速查（沿用 B1 SOP，只列不能违反的）

| 项目 | 要求 |
|---|---|
| 镜头 | 手机**后置主摄** |
| 模式 | 关闭人像/美颜/滤镜/HDR；关闪光灯 |
| 格式 | **JPG**（iPhone：设置→相机→格式→兼容性最佳） |
| 拍摄节奏 | **每张间隔 1–2 秒，禁止连拍**（连拍=近重复帧，清理成本极高） |
| 单场景上限 | 同一姿势/位置最多 4 张变体 |
| 背景 | 必须有真实设备与杂物，**不要在纯白墙/空房间拍** |
| 命名 | **只准英文/数字**，禁中文（全链路 cv2 中文路径会炸） |
| 单人出镜 | 口头同意即可，不外传、不上公开云 |

## 6. Plan B：现场采集拿不到场地怎么办

按优先级：

1. **先用 §4 + §5 两条自动线**（uploads 预标注 + 底座漏标复查）把能捞的框捞回来；
2. **向组长申请**：有实验室准入的成员 → 按本清单执行（这是唯一能治"域差异"的路径，公开数据集替代不了）；
3. **外部数据兜底**（质量差、需过四关）：Roboflow 口罩/护目镜数据集检索——但**必须满足实验室场景口径**，
   街头/医院/工厂场景一律不收（这正是本次手术移出 7,311 组的原因，不要重蹈覆辙）。

## 7. 交付与入库流程（谁做什么）

| 步骤 | 谁 | 内容 |
|---|---|---|
| 1 | 拍摄人 | 按任务包拍 → 交付文件夹绝对路径 |
| 2 | AI（我） | 预处理（HEIC→JPG、EXIF 校正、统一重命名、近重复清理） |
| 3 | AI（我） | **三向去重**：新数据 ↔ dataset1 / **dataset2（红线）** / lab_ppe 全库 |
| 4 | AI（我） | pHash 同源检测 + 脏图/水印筛查 |
| 5 | AI（我） | 预标注（`labppe_v8s.pt`）+ COCO 人员检测器补 person 框 |
| 6 | **你** | 出抽检图版 → **按编号判定**（合格/剔除/框修正） |
| 7 | AI（我） | 标注一致性审计（第 4 关）→ 并入 **train/valid**（**不动 test**） |
| 8 | AI（我） | 更新数据集数字与文档、提交 |

**硬约束**：
- 新增数据**只进 train/valid，永不进 test**（`data/lab_ppe/test` 与 `dataset2` 为红线）；
- 剔除一律**移动**到 `data/_rejected/<tag>_<日期>/`，可整体移回，**永不删除**；
- 同源图**整组划分**到同一 split，禁止跨 split 泄漏。

## 10. 她的治理决策（2026-10-08 深夜）：剔坏图 + 引入新实验室场景测试集

漏标候选审批（编号 153–192）时她确认两件事：

1. **车间系列整批剔除**：纯数字命名家族中 67 族 / 167 张为机加工车间场景（非实验室），已整批移入 `data/_rejected/workshop_series_20261008/`（详见 `docs/E4_lab_coat_plan.md` §B+8）。剔除后底座 train 1,339 图 / 4,291 框，**域纯度显著提升**——剩余数据全部为实验室/医疗/教学场景。
2. **图片重复率过高 → 引入新的实验室场景测试集**：她明确"重复率高的坏图剔除后，应引入新的实验室场景数据"。落地路径即本清单的拍摄批次（包 1–6），另外补一条**低成本替代**：从已剔除素材的反方向入手——用 `tools/prelabel_generic.py` 对**新采集的实验室实拍/公开实验室视频抽帧**做预标注草稿，人工只需校正（比从零画框快 5–10 倍）。视频抽帧优先选**多人、多机位、有口罩/护目镜特写**的实验室 vlog / 教学视频，抽帧间隔 ≥2 s（避免连帧重复，吸取 pHash 去重教训）。

> 验收口径不变：新增数据只进 train/valid；入库必过四关（红线去重 / pHash / 脏图 / 标注一致性）；每批入库后跑 `tools/eval_phase1_baseline.py` 复评。
