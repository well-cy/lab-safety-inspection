### 修复清单

| 编号 | 现象（用户可见） | 根因 | 修法 |
|---|---|---|---|
| BUG-13 | 一只手出现两个框、错归他人 | 切片复检的高包含率重复框逃逸（IoU 0.45 < 0.55 未合并） | PPE 类加「IoU≥0.40 且包含率≥85% 合并」；**person 类不做**（真人前后站位会误合并） |
| BUG-14 | 伸出本人框外的手被判给旁人 | 「精确包含优先」规则对边缘手失效 | 手套「成对先验」：已绑 PPE 者伸出的手优先归本人（守卫 IoU≥0.5） |
| BUG-15 | 相邻两人的手套全被先绑者吸走 | 成对先验副作用（BUG-14 的新增副作用） | 每人的手套满额上限 2 只，满额退出竞争；虚拟聚合人员不受限 |
| BUG-16 | 紧邻两人的手套归属随机翻转 | PPE 中心压在 person 框缘外 0.02px，退化为「面积最小」消歧 | 新增「重叠占比」优先级（PPE∩person / PPE 面积），插在精确包含之后 |
| BUG-17 | 重叠人群里真人漏检（3 人只报 2 人） | 真人 conf 被 YOLO 联合框压低（0.290），PPE 类不能跟着降阈值 | **按类阈值**：person 单独放宽 `CONF_PERSON=0.28` |
| BUG-18 | 普通近视镜被判成「护目镜」 | 模型混淆「眼镜 vs 护目镜」（假阳性 0.389 过全局 0.35） | **按类阈值**：goggles 单独收紧 `CONF_GOGGLES=0.44`（假 ≤0.389 / 真 ≥0.497，唯一可行区间中点） |
| BUG-19 | 相距很远的两人各戴一只手套，一人被误判「未戴手套」（验收报告 S2/S3/S11/S12） | 成对先验 sibling 无空间约束，作为最高优先级抢走帧内任意位置的手套 | sibling 加 40% 扩张框空间约束：空间无接触不构成「另一只手」证据；BUG-14 伸手场景本就在扩张框内，不受影响 |

### 关键设计

- **按类阈值机制**（`PPEDetector._apply_class_thresholds`）：推理统一用最低阈值跑（保证不漏），
  汇总**全部检测来源**（全图双尺度 + 切片复检）后按类收口。收口位置必须在切片之后——
  低置信假阳性常来自切片（实测假 mask 0.339、假 lab_coat 0.483 均为切片产物）。
- **两个方向相反**：person 放宽（0.28 < 0.35）、goggles 收紧（0.44 > 0.35）。
  配置集中在 `backend/config.py`，可用环境变量覆盖，**设回 0.35 即完全恢复旧行为**：
  ```bash
  set LABSAFETY_CONF_PERSON=0.35   # Windows
  set LABSAFETY_CONF_GOGGLES=0.35
  ```
- **BUG-13 → 14 → 15 → 16 是同一条规则的连环副作用链**，每次修完都复测前序案例，
  教训写入 `docs/E5_9` 第八~十节。
