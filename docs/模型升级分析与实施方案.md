## 三、任务 3：新数据集分析

### 3.1 数据集 1：LAB_PPE（vitor-ferraz-marini，7.4k 张）

页面实测信息：CC BY 4.0；Object Detection；**Dataset versions: 1（safety goggles - v1 2023-08-02）**；
**Models: 0（没有现成训练权重，必须自己训练）**；13 个类别：

```
Mask, glove, Glove, Gloves, Goggles, googles, safety goggles,
lab coat, Lab coat, Coverall, Face_Shield, lab shoe, protective head cap
```

| 关注点 | 分析结论 |
|---|---|
| Lab Coat 是真实验服吗 | ✅ **是**。`lab coat`/`Lab coat` 是独立类别（就是白大褂），不再靠 medical-suit 近似。样张可见 "Gloves, Lab coat, Mask" 同框真实场景 |
| Gloves 是实验手套吗 | ✅ 是。丁腈/乳胶手套，且大量特写样张（如 "stock-photo-latex-glove-isolated-white-background"）。⚠️ 风险：**白底孤立物体特写偏多**，可能让模型偏好"摆拍"视角，真实场景泛化需靠场景样张 |
| Mask 适合实验室吗 | ✅ 医用口罩，与现系统语义一致 |
| **有没有 Person** | ❌ **没有 person 类！** 这是本数据集最大的坑——不能单独训出"人+PPE"一体模型 |
| 类别干净吗 | ❌ 脏。大小写重复（glove/Glove/Gloves、lab coat/Lab coat、Goggles/googles/safety goggles）共 3 组重复，需下载后**重映射合并** |
| YOLO 格式 | Roboflow Universe 导出可选 YOLOv8 格式（zip，含 data.yaml + train/valid/test 划分） |
| 下载方式 | 需注册免费 Roboflow 账号拿 API key（`roboflow` 包或网页直接 Download ZIP） |
| 可直接用于 YOLOv8？ | ✅ 导出即标准 YOLO 结构，`YOLO("yolov8s.pt").train(data=...)` 直接吃 |
| 需要重新训练吗 | **必须**（页面 Models: 0，无现成权重） |
| 能直接用现成权重 baseline 吗 | ❌ 不能。所谓 baseline = 我们自己用它训一版 |

### 3.2 数据集 2：LAB PPE（masters-ppe，251 张）

页面实测信息：CC BY 4.0；251 张；10 类：

```
Person, Mask, Glasses, Gloves, Lab Coat, Shoes,
No Glasses, No Gloves, No Lab Coat, No Mask
```

| 关注点 | 分析结论 |
|---|---|
| 真实场景吗 | ✅ 样张文件名（如 `019_0630_022162.jpg`）呈监控式命名，像是**真实实验室监控/固定机位**照片，含 "Gloves, Mask, No Glasses, No Lab Coat, Person" 同框 |

| Lab Coat | ✅ 真正的实验服类 |
| 负样本类（No Gloves 等） | 有意思但**不建议用**：我们的规则引擎靠"正类缺失"推断违规，No* 类用不上；且引入需改规则引擎，违背最小改动 |
| 规模 | ❌ 只有 251 张，训练不够、**测试正好** |

### 3.3 参考项目：yolo-ppe-detection（GitHub）

实测 README：YOLOv8 **两阶段**——先用 person 模型检测全图人员，再对每个 person **裁剪**后用第二个 PPE 模型检测。用的是工业/建筑 PPE 数据集（无 lab coat），提供的是 yolov8n 和思路，**权重不能直接用**。

对本项目的价值：验证了"person 模型 + PPE 模型分离"是可行范式——正好和我们要推荐的方案 A（双模型）思路一致；但我们**不需要裁剪**（我们的 ppe_matcher 本来就用空间归属把 PPE 绑到人），直接合并两个模型的检测框即可，改动更小。

### 3.4 综合判断

| 判据 | 数据集 1 (7.4k) | 数据集 2 (251) |
|---|---|---|
| 角色 | **训练 + 验证**（PPE 4 类） | **锁死的独立测试集**（含 Person，可顺带评 SH17 person） |
| 能否直接替换现模型 | ❌ 无 person、无现成权重 | ❌ 太小 |
| 是否解决 lab_coat 问题 | ✅ 有真 lab coat 类，配合训练 | ✅（用于验证） |

**结论：数据集 1 训练 PPE 模型 + 沿用 SH17 检 person（方案 A 双模型）是当前约束下的最优解。**

## 四、任务 4：最小改动方案（推荐方案 A：双模型）

### 4.1 三个候选方案对比

| 方案 | 做法 | 改动量 | 风险 | 评价 |
|---|---|---|---|---|
| **A. 双模型并行（推荐）** | SH17 只取 person；新 LAB_PPE 模型出 mask/gloves/lab_coat/goggles；两路 Detection 拼接 | 小（2 个文件） | person 检测保持现有已验证水平 | ✅ 最稳，且与 GitHub 参考项目范式一致 |
| B. 单模型替换 | 用数据集 1 训一个 4 类模型直接换掉 SH17 | 中 | **没有 person** → 链路直接失效；除非混入别的人体数据，工程量失控 | ❌ 数据集 1 无 person，不可行 |
| C. 两阶段裁剪 | 完全照抄 GitHub：person 检测→crop→crop 内 PPE 检测 | 大（改 processor/ppe_matcher） | 坐标系换算复杂、延迟翻倍、crop 丢失全局上下文 | ❌ 过度设计 |

### 4.2 方案 A 详细设计

**数据流（只改加粗部分）**：

```
帧 → 【PPEDetector：SH17(只留 person) + LAB_PPE 模型(PPE 4类) 两路推理合并】
   → match_person_ppe（不改）→ ROI（不改）→ 规则引擎（不改）
   → 事件/截图/入库/前端（全不改）
```

**模型输出转换与 class id 统一**：
- 新模型训练时定义 4 类：`0 mask, 1 gloves, 2 lab_coat, 3 goggles`（id 由训练 data.yaml 决定，**无所谓是多少**）；
- `map_class()` 已按**名称**映射：`"mask"→mask`、`"gloves"→gloves`、`"lab coat"→_normalize→"lab-coat"`（命中子串兜底 `coat`→lab_coat）、`"goggles"→goggles`。**名称映射天然统一，无需任何 id 转换层**；
- `Coverall`（连体防护服）建议映射为 `lab_coat`（与旧 medical-suit 语义一致：身体防护=实验服规则项），也可在训练时直接并入 lab_coat 类（推荐后者，见 4.4）。

### 4.4 为什么 person 继续用 SH17

- 实测 person 是 SH17 最稳的类（t01-t10 置信度 0.5~0.92，仅 t10 空景误检 2 框）；
- 数据集 1 无 person 标签、数据集 2 只有 251 张——都不足以单独训 person；
- SH17 是现成权重，零训练成本。t10 误检问题用"conf 阈值 person 单独调到 0.5"即可缓解（可顺手在 detector 里做，+2 行）。

## 五、任务 5：实验方案（课程项目级，防数据泄漏）

### 5.1 数据角色分配（防泄漏的核心）

| 数据 | 角色 | 是否进训练 | 说明 |
|---|---|---|---|
| 数据集 1 train/valid split | 训练/验证 | ✅ | Roboflow 自带划分，原样使用 |
| 数据集 1 test split | 同分布测试 | ❌ | 训练时 `model.train()` 只碰 train/valid |
| **数据集 2 全部 251 张** | **独立外部测试集（锁死）** | ❌ **永不训练** | 与训练数据不同源，是"真实验服+真实场景"的最终裁判 |
| t01–t10 公开图 | 定性演示 | ❌ | 已有人工复核 GT（错误分析表），做前后对比展示 |
| demo_lab_video.mp4 | 端到端演示 | ❌ | 系统集成回归用 |

**防泄漏红线**：
1. 数据集 2 的任何图片不得出现在任何训练/验证集中（哪怕"就加几张"）；
2. 数据集 1 的 test split 目录训练期间只读、不扩充；
3. 转换标签脚本记录原始文件名→新文件名映射（`manifest.csv`），可追溯；
4. 若后续需要更多训练数据（E4 阶段），**另找第三个数据集或补拍**，不得动数据集 2。
