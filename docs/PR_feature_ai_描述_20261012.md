## 背景

本项目为《基于计算机视觉的实验室安全智能巡检与违规预警系统》。本 PR 将 **AI 检测线**
与 **数据线** 整体合入 `develop`，包含从数据采集/审核、模型训练验收、后处理管线加固到
文档沉淀的完整链路。

## 本 PR 包含什么

### 1. 类别体系与模型（6 类）

- **类别体系**：`{0:person, 1:mask, 2:gloves, 3:lab_coat, 4:goggles, 5:coverall}`
  - `coverall`（连体防护服）**独立成类**：医用连体防护服**不满足** lab_coat 要求，
    穿连体服判「未穿实验服」（推翻早期 Route A「连体服视作实验服」的口径）
  - 前端已同步 `coverall` 中文名映射
  - `backend/config.py` 的 `ALLOWED_PPE` **故意不含 coverall**——它是违规证据类，不是区域可配置 PPE
- **现役模型**：`ai/model/labppe_v8s.pt`（YOLOv8s，6 类，100 epochs 完整训练）
  - 换装机制：环境变量 `LABSAFETY_MODEL_PATH` > `ai/model/labppe_v8s.pt` > 旧模型兜底
  - `detector.raw_names` 从模型文件**动态读取**、按类别名映射 → **换模型零代码改动**
  - 一键换装脚本 `tools/swap_5cls_model.py --zip <包>`：自动识别 4/5/6 类、校验类别名、备份旧模型

### 2. 后处理管线加固（关键修复）

| # | 问题 | 根因 | 提交 |
|---|---|---|---|
| 1 | 不管多少人都只显示 1 人 | `_nms_merge` 做了**跨类**贪心 NMS，person 框被 lab_coat 框抑制；且遍历字符串集合导致抑制方向随进程随机化 | `6e598ba` |
| 2 | 长在身上的真手套被当倒影剔除 | `_is_reflection` 缺物理守卫 | `e86b0d1` |
| 3 | 坐姿者的 PPE 被旁边站立者抢走 | 归属规则「取面积最小者」把框外伸出手套判给了他人 | `bfa24c4` |
| 4 | 画面底部的真手被当「鞋/脚」剔除 | `_GLOVES_BOTTOM_Y=0.86` 规则缺「长在身上」守卫 | `236d9cb` |

另有此前 7 轮增强：双尺度/切片复检、几何过滤、倒影过滤、手套分级准入、伪 person 框清理
（碎片框 + 联合框 + 迭代删除）、PPE 归属扩张框兜底、碎片判定 PPE 豁免等。

**设计原则**：检测 → 归属 → 判定 → 分级 四层解耦，模型弱项由后处理合理性过滤兜住，
不直接变成误报。

### 3. 数据集与数据线

- 训练集 `data/lab_ppe`：**3,221 图 / 12,374 框**（train 2,007 / valid 407 / test 807）
- 类别分布：gloves 8,088 / person 3,340 / goggles 2,868 / lab_coat 2,098 / mask 1,823 / coverall 402
- 多轮人工审核批次入库（person 框选 p0_x 系列、lc13 lab_coat 系列、CPPE-5 复核子集等）
- 外部数据集接入评估：多份候选做四关审计（域一致性 / 标注一致性 / 去重 / 红线合规），
  结论与取舍均有文档记录

### 4. 工具链与文档

- `ai/`、`tools/`（约 113 个脚本：筛查、去重、审核编辑器、落库、评测、换装）、`tests/` 回归用例
- 文档 28 篇（`docs/`），含采集 SOP、数据审计、训练指南（AI Studio / Kaggle）、

## 已知限制（非缺陷，已定位到根因）

1. **医用连体防护服**在旧标签处理中被大量丢弃 → 跨域场景 `lab_coat` 召回偏低（需补数据）
2. **mask 召回偏低**（46~77%）——训练集量级偏小且视觉变异性极大
3. **机械臂/机器人等「像人非人」目标可能误检为 person**——训练集无此类负样本
4. valid 集 **57.7% 的图「有人但未标 person」** → person 的 AP50 指标（0.470）**失真**，
   应以真实召回 81.5% 为准；报告/答辩引用该指标时需说明口径
