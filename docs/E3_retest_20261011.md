## 0. 与原始 E3 的关系

原始 E3（`docs/E3_eval_report.md`，2026-09-06）结论：lab_coat 跨域 F1 仅 **0.340**（SH17 0.159），**未达 E4 门限 0.70**，
是当时最大短板。此后项目推进了多轮数据补标，其中与本类最相关的是：
- **person 补标线**（B+33~45，10 批）：train person 框 1,376 → 2,200；
- **lc13 lab_coat 画框线**（并行，B+38~46）：train 新增 `lc13_*` 白大褂多样样本，lab_coat 框大幅增加（→ 1,328）。

**本次复测目的**：在**同一口径、同一 external_test** 上重跑 E3，回答「补标到底改善了没有、lab_coat 是否接近门限」。

⚠️ **权重来源已确证（重要）**：本次复测所用 `ai/model/labppe_v8s.pt` 与 `outputs/e4_retrain_unpack/best.pt`
**md5 完全一致（`0f15d7e4a8fe77e7b05d36db90f86dde`）**，即**当前网模型就是 E4 重训产物**（E4，30 epochs，valid mAP50 0.737；
见 `docs/E5_补数据与重训方案.md` 第 10 行）。而原始 E3 报告用的是 **E2 模型**（`runs/e2/labppe_v8s/weights/best.pt`，epoch 49）。
因此本次对比的实质是 **E2 模型（旧）→ E4 重训模型（新）** 的跨版本对比，不是「同一权重重跑」。
data/**lab_ppe 补标是本轮 E4 重训的训练数据来源**，故 lab_coat 的跃升正是「补标 → 重训 → 跨域改善」这条链路的最终验证。

> 因此 mask/gloves/goggles 的下降是**重训带来的类别间再平衡**（训练数据大幅扩充 lab_coat 后，模型容量向该类倾斜），

### 2.3 关键结论

1. **lab_coat 跨域短板已被补齐** ✅：R 20.5% → **93.7%**、F1 → **89.1%**、AP@50 → **0.901**。
   **首次越过 E4 门限（F1≥0.70）**，且幅度很大。这是 person 补标线 + lc13 白大褂多样样本补标 → E4 重训这一整条链路的直接成效。
2. **mask 仍稳定受益**（F1 71.1% vs SH17 56.5%），双模型方案下 mask 交给 LAB_PPE 仍是净收益。
3. **gloves 出现反转**：本次 SH17（F1 78.5%）**优于** LAB_PPE（64.9%）。重训后 LAB_PPE 的 gloves 回退 10.8pt。
   **建议 gloves 路由改回 SH17**（详见 §5）。
4. **goggles 仍是最大短板**（LAB_PPE F1 22.1%，SH17 49.8%）：重训后进一步回退。**goggles 应走 SH17**。
5. **person**：SH17 F1 95.8%，双模型分工成立（person 由 SH17 负责不变）。

## 4. 综合分析

1. **lab_coat 跨域短板已实质解决**：external F1 0.340 → **0.891**，首过 E4 门限 0.70；t02/t07 真实白大褂照片从「完全漏检」变为「正确识别」。
2. **mAP@50（4 PPE）0.364 → 0.514**（+41% 相对 SH17）；对 SH17 的 PPE 优势进一步扩大（原 0.438 vs 0.364，现 0.514 vs 0.364）。
3. **路由结论（相对原始 E3 的建议 ①「混合路由」应更新）**：
   - 原始建议：person+goggles 走 SH17，mask+gloves+lab_coat 走 LAB_PPE。
   - **本次建议**：person+goggles+**gloves** 走 SH17，mask+**lab_coat** 走 LAB_PPE。
     （gloves 因本次 LAB_PPE 侧回退，改由 SH17 更优；lab_coat 已可放心交给 LAB_PPE。）
4. **规则引擎**：两轮测试 0 张规则错误，检测层仍是唯一误差来源（与原结论一致）。
5. **t06 连体防护服语义**：问题仍在（连体服不算 lab_coat → 报「缺实验服/缺口罩」），属**业务规则设计取舍**，需你拍板是否把「防护服」列为实验服等价物。本次最小化影响：t06 从「严重违规(缺 3 项)」变为「一般违规(缺 1 项)」，比旧版更接近真实。
