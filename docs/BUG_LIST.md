## 二、BUG-007 修复指引（供前端参考）

已定位到具体代码位置，修复量很小：

1. **字段用错**（必须改）
   - 位置：`backend/static/index.html:363`
   - 现状：`$('v-count').textContent = \`共 ${r.total} 条记录\`;`
   - 改法：把 `r.total` 改为 `r.total_count`
   - 依据：接口 `GET /api/violations` 同时返回两个字段（`backend/main.py:195`），
     其中 `total` 保持契约原语义「本次返回条数」，`total_count` 才是符合筛选条件的总条数。
     **后端无需改动，契约字段定义见 docs/INTERFACE_CONTRACT.md §6.5。**

2. **缺少分页**（建议一并补上）
   - 位置：`backend/static/index.html` 的 `loadViolations()`（约 348-365 行）
   - 现状：调用 `/api/violations?` 时未传 `limit`/`offset`，页面也没有翻页控件
   - 改法：在函数内维护当前页，请求时带上 `limit`（每页条数）与 `offset`（跳过条数），
     并在表格下方渲染"上一页 / 第 N/M 页 / 下一页"
   - 依据：接口已支持 `limit`（默认 200，取值 1~1000）与 `offset`（≥0，默认 0），后端无需改动

3. **验证方法**：把 `/api/violations` 造出 200 条以上记录（或用 `limit` 观察
   `total` 与 `total_count` 的数值差异），确认统计文字与翻页均正确。
