# 【锁定策略】—— 为什么用区间而不是 ==
#   下界：保持项目原有下界不变。提高下界会强制已装好环境的成员升级，
#         有破坏现有可运行环境的风险，而收益很小。
#   上界：新增 `<下一个大版本` 限制，防止未来大版本不兼容导致
#         "某天 pip install 之后突然跑不起来"。
#
#   不写 == 精确锁定的原因：torch / torchvision / opencv-python 的
#   wheel 与平台强绑定（Windows+CUDA / macOS / Linux 各不相同），
#   精确锁死会导致部分成员根本装不上。
#   本机实测的精确版本见 test-reports/task07-06-dependencies.md。
#
# 【安装】见 README「如何运行」或 test-reports/task07-01-windows-runbook.md
